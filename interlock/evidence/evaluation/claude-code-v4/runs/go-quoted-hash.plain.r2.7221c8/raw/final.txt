I added `TestQuotedHash` to `parser_test.go`. It covers the quoted `#`, `"x" # note`, `"C:\\temp"`, and a value that has an escaped quote and a `#` inside quotes followed by a trailing comment. The existing `TestValues` already checks `port = 8080 # http`.

One behaviour change: text after the closing quote that isn't a comment, such as `"x" y`, now gives the error `unexpected text after quoted value`. Before, it gave `unterminated quoted value`.
