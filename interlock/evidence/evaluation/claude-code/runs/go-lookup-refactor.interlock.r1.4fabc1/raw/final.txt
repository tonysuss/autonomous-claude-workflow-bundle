I added `lookup(section, key string) (string, error)` to `getters.go`, and `Get`, `GetInt`, `GetBool` and `GetDuration` now all go through it. `lookup` is the only place that reads `c.sections`.

`GetBool` words its missing-key error differently from the other three: it says `key %q not set`, where the others say `no key %q`. To keep every message identical, `lookup` returns a small unexported `missingKeyError` for a missing key, and `GetBool` detects it with `errors.As` and returns its original wording.

`go test ./...` passes on the refactored tree (checked with `interlock check run --criterion regression`), and `go vet` and `gofmt` are clean. I recorded a `tested` claim for `regression`. The `structure` and `behaviour` criteria need the independent verifier, so I did not claim them.
